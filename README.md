# aubital.f-90.co.uk

Home, privacy, and support for Aubital, hosted as a subdomain of f-90.

## Stack

Plain HTML / CSS / JS. Funnel Display. Nested CSS with variables.

## Local preview

```sh
cd /Users/becter/code/aubital-site
python3 -m http.server 8080
```

## Deploy

GitHub Pages from this repo’s root on `main`, custom domain `aubital.f-90.co.uk`.

DNS: CNAME `aubital` → `utopastac.github.io`. Keep the root `CNAME` file as `aubital.f-90.co.uk`.

Listing URLs:

- Marketing: `https://aubital.f-90.co.uk/`
- Support: `https://aubital.f-90.co.uk/support/`
- Privacy Policy: `https://aubital.f-90.co.uk/privacy/`
